jq filter with a trailing on
========================================

  read tool
    expect gone = exit 1
    capture x = jq .a | select(.b == "x y # z") on gone

    capture blob? = jq json .
    capture secret tok = file {korin.out}/r.json jq .token
    capture word = jq .on
    capture last = jq .a on # not an expect
